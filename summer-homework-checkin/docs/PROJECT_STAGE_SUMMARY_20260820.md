#### v1.5.0 新增功能明细

1. **数据模型扩展**（迁移 010→011→012）
   - `PetSpecies.diet_type`：饮食类型（carnivore/herbivore/omnivore/special）
   - `PetFeedItem.suitability_level / suitability_note`：食物适配等级与说明
   - `PetFeedLog.suitability_result`：每次喂养的适配性结果记录
   - `PetAdoption.sick_until / perfect_streak`：生病截止时间与连击计数

2. **饮食-食物适配矩阵**（`pet_service.py`）
   - 4 种饮食类型 × 8 种食物分类的完整映射
   - 5 级适配评价：perfect ✅ / suitable 👍 / caution ⚠️ / warning ❗ / danger 🚫
   - 管理员手动设置优先级最高，支持按物种特化

3. **生态反馈系统**
   - 生病机制：喂食 warning/caution 食物触发 2 小时生病状态，期间禁止喂养
   - 连击加成：连续 3 次 perfect 喂养触发 +20% XP 加成（`round()` 修复浮点精度）
   - 生病倒计时：前端实时显示剩余恢复时间

4. **管理后台增强**
   - 适配性矩阵视图：33 种宠物 × 12 种食物的颜色块矩阵
   - 异常喂养记录查询：warning/caution 级别的喂养事件
   - 食物适配等级手动调整接口

5. **前端交互**
   - 食物卡片显示适配标识（5 级 emoji + 颜色）
   - danger 食物置灰不可点击，warning 食物弹确认框
   - 宠物卡片增加生病横幅、饮食标签、连击动画

## 三、技术架构总结

### 3.1 技术栈应用

| 层次 | 技术选型 | 说明 |
| --- | --- | --- |
| 后端框架 | FastAPI 0.115.0 | 异步高性能，自动 OpenAPI 文档 |
| 数据库 | SQLite + WAL | 轻量部署，WAL 模式提升并发 |
| ORM | SQLAlchemy 2.0.35 | 参数化查询防 SQL 注入 |
| 数据库迁移 | Alembic（12 版本） | 防御式迁移，双向可逆 |
| 前端框架 | Vue 3.5.41（本地托管） | CDN 替代为 vendor 目录 |
| 容器化 | Docker + Compose | 安全加固：只读 FS、cap_drop、资源限额 |
| 反向代理 | Nginx | 子路径适配、HTTPS 预备 |

### 3.2 安全加固措施

| 措施 | 实现方式 |
| --- | --- |
| 速率限制 | 登录 5 次锁定 15 分钟 + 60 秒频率限制 |
| CORS 白名单 | 生产不含 localhost，沿用现有公网入口 |
| 端口绑定 | 仅 127.0.0.1（本地 8003/8001，生产 9000） |
| 密钥管理 | 环境变量注入，`.secret_key` 权限 600 |
| 容器安全 | read_only + cap_drop ALL + no-new-privileges |
| CSP 响应头 | 同源策略，移除外部 CDN 域名 |
| API 文档 | 生产环境 PRODUCTION=1 关闭 /docs /redoc |
| 上传安全 | 认证化 API + 路径穿越防护 + 归属校验 |

## 五、代码质量与仓库治理

- **分层架构**：routers（协议）/ services（业务）/ utils（工具），业务逻辑不散落路由
- **时间处理**：收敛至 `timeutil.now_local()` 单一入口 + Dockerfile `TZ=Asia/Shanghai`
- **迁移策略**：防御式编写（列存在检查），双向可逆，历史数据零丢失
- **`.gitignore` 门禁**：密钥/数据库/上传/备份/日志/临时文件全类目拦截
- **文档同步**：docs/ 16 份文档随代码演进，每版本更新 CHANGELOG
- **安全归档**：渗透测试报告 + 安全整改报告 + 上线前测试报告
