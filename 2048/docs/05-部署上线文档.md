## 部署架构

本项目为纯静态H5应用，无需后端服务、数据库或应用服务器。部署架构极简：

```
用户浏览器（手机）
    │
    │ HTTPS
    ▼
Nginx / CDN（静态文件托管）
    │
    ├── index.html
    ├── css/style.css
    └── js/game.js
```

所有游戏逻辑在浏览器端运行，数据通过LocalStorage存储在用户本地，服务端仅需提供静态文件访问。

## 部署方式一：Nginx部署

### 1. 上传文件

将`src/`目录下的所有文件上传到服务器Web根目录：

```bash
# 服务器目录结构
/var/www/2048/
├── index.html
├── css/
│   └── style.css
└── js/
    └── game.js
```

上传命令示例：
```bash
scp -r src/* user@server:/var/www/2048/
```

### 2. Nginx配置

创建Nginx站点配置文件 `/etc/nginx/conf.d/2048.conf`：

```nginx
server {
    listen 80;
    server_name 2048.example.com;

    root /var/www/2048;
    index index.html;

    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/javascript text/javascript;
    gzip_min_length 512;

    # 缓存策略
    location ~* \.(css|js)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    location / {
        try_files $uri $uri/ /index.html;
        add_header Cache-Control "no-cache";
    }

    # 安全头
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
}
```

### 3. 启用HTTPS（推荐）

使用Let's Encrypt免费证书：

```bash
# 安装certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书并自动配置Nginx
sudo certbot --nginx -d 2048.example.com

# 自动续期（certbot会自动设置cron任务）
sudo certbot renew --dry-run
```

### 4. 启动服务

```bash
# 测试配置
sudo nginx -t

# 重载配置
sudo nginx -s reload
```

## 部署方式二：静态托管平台

本项目可直接部署到任意静态文件托管平台，无需构建步骤：

| 平台 | 部署方式 |
|------|---------|
| GitHub Pages | 将src目录内容推送到gh-pages分支 |
| Vercel | `vercel deploy --prod`，输出目录设为src |
| Netlify | 拖拽src目录到Netlify部署面板 |
| Cloudflare Pages | 连接Git仓库，构建命令留空，输出目录设为src |
| 阿里云OSS | 创建Bucket，上传src目录文件，开启静态网站托管 |

### Vercel部署示例

```bash
# 安装Vercel CLI
npm i -g vercel

# 在项目根目录创建vercel.json
cat > vercel.json << 'EOF'
{
  "version": 2,
  "builds": [
    { "src": "src/**", "use": "@vercel/static" }
  ],
  "routes": [
    { "src": "/(.*)", "dest": "/src/$1" }
  ]
}
EOF

# 部署
vercel deploy --prod
```

### 微信公众号H5接入

如需在微信公众号菜单中接入游戏：

1. 将游戏部署到HTTPS域名（微信要求）
2. 在微信公众号后台 → 自定义菜单 → 设置跳转URL
3. 配置JS安全域名（公众号设置 → 功能设置 → JS接口安全域名）
4. 如需分享功能，需在微信公众平台配置域名并接入微信JS-SDK（当前版本未集成）

## 部署方式三：Docker部署

### Dockerfile

```dockerfile
FROM nginx:alpine

COPY src/ /usr/share/nginx/html/

COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

### 构建和运行

```bash
# 构建镜像
docker build -t game2048-h5 .

# 运行容器
docker run -d -p 8080:80 --name game2048 game2048-h5

# 访问
# http://localhost:8080
```

## 回滚方案

如上线后发现严重问题，回滚步骤：

1. 保留上一版本文件备份（部署前备份旧版本）
2. 将备份文件覆盖回Web目录
3. 验证回滚后功能正常
4. Nginx静态文件无需重启服务，覆盖即生效

```bash
# 部署前备份
cp -r /var/www/2048 /var/www/2048_backup_$(date +%Y%m%d)

# 回滚
rm -rf /var/www/2048
cp -r /var/www/2048_backup_20260807 /var/www/2048
```

## 监控建议

对于纯静态H5应用，监控重点：

- 使用CDN访问日志监控流量和异常状态码
- 接入前端错误监控（如Sentry）捕获JS运行时错误
- 通过Google Analytics或百度统计追踪访问量和用户行为
- 关注微信浏览器兼容性问题（用户反馈渠道）
