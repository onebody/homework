## 缺陷记录与修复

### 缺陷 #1：下移方向旋转错误

| 属性 | 内容 |
|------|------|
| 严重程度 | 严重（Blocker） |
| 发现阶段 | 单元测试 |
| 描述 | 执行下移操作时，方块合并位置错误。两个2在列方向上下排列，下移后合并结果出现在错误的列位置 |
| 原因 | `_rotateBack`方法中down方向的逆变换矩阵计算错误，列索引遍历方向不正确 |
| 修复 | 将`for (c = size-1; c >= 0; c--) newRow.push(board[c][r])`修正为`for (c = 0; c < size; c++) newRow.push(board[c][size-1-r])` |
| 状态 | 已修复并验证 |

### 缺陷 #2：游戏结束状态未在无法移动时设置

| 属性 | 内容 |
|------|------|
| 严重程度 | 高（Critical） |
| 发现阶段 | 单元测试 |
| 描述 | 当棋盘已满且无可合并方块时，玩家尝试移动后游戏结束状态未被设置，导致游戏卡在无法操作但不显示结束界面的状态 |
| 原因 | `canMove()`检查仅在`moved=true`时执行，但当棋盘已满无法移动时`moved=false`，导致`over`标志永远不被设置 |
| 修复 | 将`canMove()`检查移到`if (moved)`块外部，每次移动尝试后均检查游戏是否结束 |
| 状态 | 已修复并验证 |

### 缺陷 #3：Node.js测试环境DOM引用错误

| 属性 | 内容 |
|------|------|
| 严重程度 | 中（Major） |
| 发现阶段 | 单元测试首次运行 |
| 描述 | 在Node.js环境中运行单元测试时，模块加载阶段直接访问`document.getElementById`导致ReferenceError |
| 原因 | DOM元素查询在IIFE顶层执行，Node.js环境无document对象 |
| 修复 | 将DOM元素查询延迟到`init()`函数中执行，模块加载时仅声明变量 |
| 状态 | 已修复并验证 |
