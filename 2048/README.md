# 2048 手机版 H5 游戏

基于纯原生 HTML5 + CSS3 + JavaScript 开发的移动端 2048 数字合并游戏，无需后端服务，即开即玩。

## 在线体验

使用手机浏览器或PC浏览器打开 `src/index.html` 即可游玩。

## 游戏玩法

在 4x4 的棋盘上，通过滑动屏幕（手机）或方向键（PC）控制所有方块朝同一方向移动。相同数字的方块碰撞时合并为两者之和，每次移动后随机生成一个新方块（2或4）。目标是合成 **2048**。

## 功能特性

- 触屏滑动操作，支持上下左右四个方向
- 键盘方向键和 WASD 操作（PC调试用）
- 实时分数显示和最高分记录
- 游戏状态自动保存，刷新不丢失
- 合成2048胜利提示，可继续挑战更高分数
- 方块出现和合并动画
- 响应式设计，适配320px-480px手机屏幕
- 横屏模式自适应
- 零第三方依赖，纯原生实现

## 快速开始

### 本地运行

直接用浏览器打开 `src/index.html` 文件即可，无需搭建服务器。

如需通过HTTP访问（推荐，避免某些浏览器的本地文件限制）：

```bash
# 使用Python启动简易HTTP服务器
cd src
python3 -m http.server 8080

# 或使用Node.js
npx serve src
```

然后访问 `http://localhost:8080`。

### 运行测试

```bash
node tests/game.test.js
```

## 核心架构

游戏采用三层架构，逻辑层与表现层分离：

- **逻辑层**：`Game2048` 类封装棋盘数据、移动合并算法、分数计算、胜负判定，不依赖DOM，可独立单元测试
- **表现层**：DOM渲染控制器，调用Game2048实例方法获取状态并渲染页面
- **数据层**：LocalStorage，持久化游戏存档和最高分

移动算法通过"旋转棋盘"将四个方向统一为左移处理：将棋盘旋转使目标方向变为左，对每行执行滑动合并，再旋转回原方向。
